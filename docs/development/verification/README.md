# 検証の索引

[検証方針](strategy.md) で対象と方法を確認し、必要なテーマのケースへ進む。

## ケースを探す

まだ検証ケースはない。
ケースを定義したら、次の形式で表へ加える。
ケース ID は、テーマを表す英大文字の接頭辞と連番（例：`IT-01`）とし、再利用しない。

```markdown
| ケース群 | 定義 | 関連する要求 |
| --- | --- | --- |
| IT-01〜IT-10 | [結合試験のケース](ケースを定義した文書.md) | FR-001 |
```

ケースを定義する文書は、この索引と同じディレクトリに置く。
各ケースには、確かめる性質、前提、操作、期待結果、観測方法、合否の根拠を書く。

## 調査・検証の結果

調査や試作、検証を実施した結果は [記録](../records/README.md) に置く。
